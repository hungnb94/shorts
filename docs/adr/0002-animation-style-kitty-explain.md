# Animation Style: Kitty Explain Format

Chọn "Kitty Explain" style (animated mascot + pop-up text + wild subtitles) làm format chính, vì wiki case study chứng minh format này đạt 4.4M views trong 1 tuần. Dễ sản xuất hàng loạt (đổi character/voice/text giữ skeleton), dễ AB test. Trade-off: format có thể bão hòa → cần pivot dựa trên data. Khó reverse vì toolchain + template đầu tư cụ thể cho format này.
