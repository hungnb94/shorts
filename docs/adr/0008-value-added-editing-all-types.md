# Value-Added Editing Expanded to All 7 Video Types

Value-Added Editing (VAE) mở rộng từ Clip Curation Edit (#7) sang TẤT CẢ 7 video types. Trước đây value-adds chỉ tồn tại trong Clip Curation Edit (ADR 0007) như legal requirement (Transformative Gate rule 2). Giờ value-adds trở thành AB variable cho mọi type: "có value-add vs không" hoặc "type A vs B" trên cùng 1 animation type. Kiến trúc: value-add layer tách khỏi renderer chính — render base video trước, rồi composite overlay (PIL/ffmpeg, toolchain có sẵn). KHÔNG thêm face cam / green screen reaction — giữ faceless moat (ADR 0002). Value-add vocabulary: 9 types (6 hiện có từ ADR 0007 + 3 mới: this_or_that_overlay, split_screen_comparison, timeline_overlay). multi_source_mashup = clip-only (cần footage). Transformative Gate KHÔNG đổi — vẫn chỉ apply cho Clip Curation Edit (animation = zero-footage, không copyright risk).
