# Multi-Format Video Types (Not Single Format)

6 video types xoay vòng: (1) Stock Footage, (2) Kinetic Typography, (3) Data Viz, (4) HTML/CSS Motion Graphics, (5) Whiteboard Sketch, (6) Meme/Notification. Video Type là AB variable chính — cùng topic, render bằng 2 types khác nhau → test type nào có AVD cao nhất. Lý do: 6 videos/ngày cùng visual = chán, audience scroll qua. Visual diversity giữa videos = quan trọng bằng diversity trong 1 video. Toolchain: PIL + ffmpeg + Playwright (đã verify working). Đổi type = đổi render function, giữ nguyên script + TTS.
