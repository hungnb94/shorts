# Capytech V7 — Charge Test Design

Status: Proceeded by best judgment from the user's explicit request to build a new source-faithful Capybluh-inspired Short.

## Goal

Create a 50–56 second, speech-free, general-audience visual-comedy Short that copies the proven causal grammar of Capybluh's long `1s vs 1h` family without copying its character, palette, stage, props, or exact jokes.

Primary business target: reduce `Viewed vs swiped away` loss below 20% after a mature 48-hour measurement window. This is a target, not a guaranteed outcome.

## Backward-planned payoff

Final payoff: after progressively longer charging tests, the one-hour test overcharges the same phone until it swells like a balloon, lifts the capybara, pops, and resets to 1% for the loop.

Signature moment: one physical object causes a full-body consequence—the swollen phone pulls the capybara off the table plane.

Expectation contract:

- Title: a charging-time comparison from 1 second to 1 hour.
- Frame 0: the same phone at 1%, the cable already approaching the port, and the complete `1s / 1m / 10m / 1h` tracker.
- First action: plug-in begins immediately.
- Payoff: the one-hour state physically overwhelms the mascot.

All four promise the same subject, repeated action, scalar, and payoff.

## Source-native topology

`same phone + same plug-in action + increasing charge time + escalating visible result`

Hard invariants:

1. One stage and fixed camera.
2. One phone and one cable.
3. One repeated verb: plug in.
4. One independent variable: charging time.
5. Each round: action -> visible result -> reaction.
6. Tracker visible from frame 0.
7. First action by 0.3s.
8. No standalone intro.
9. No explanatory portal, scoreboard, scanner, or unrelated secondary plot.
10. The exact final artifact remains 50–56s, 1080x1920, H.264 with audio.

## CTA integration

Project policy requires a custom CTA beginning at 38–42s. It remains story-native while the phone is actively swelling:

- 38.4–39.4s: compact `LIKE` control;
- 39.5–40.5s: compact `SUB` control;
- 40.6–41.8s: compact `COMMENT 1H` control.

The CTA occupies less than 15% of the frame and never stops the experiment.

## Audience

General audience, family-friendly, not specifically directed at children. There is no nursery language, child instruction, educational preschool framing, or child-character premise. The visual joke is a general phone-battery experience.

## Production route

No paid generation. Build a deterministic stylized 3D scene in Blender, then composite only the minimal tracker/CTA/watermark locally. This avoids the previous five-shot generative-footage constraint and preserves hand-object physics, identity, stage, camera, and prop state.

## Blocking gates

- Source-format declaration remains one line and one scalar.
- Frame 0 visibly includes mascot, phone, cable action, and complete tracker.
- Every stage resolves with action/result/reaction.
- No decorative-only interval longer than 2 seconds.
- CTA continues the swelling action.
- Exact-final full decode, black/freeze/silence/loudness checks pass.
- Hook and full contact sheets receive manual review.
- Public-upload parity must be run after any future upload; local QC is not public QC.
