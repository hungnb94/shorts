## Production scope

V9 replaces V8's animation-only phone-drop ladder with a multi-source real-footage escalation. The editorial claim is narrow: a phone in the selected 300-foot test visibly separates, while a different phone in the selected 1,000-foot test retains a powered display. This is not a controlled durability comparison. Devices, surfaces, and methods differ.

Phase 2 code is implemented. Canonical TTS, base rendering, compositing, media QC, exact-final hashes, and human review have not been run in this sandbox and must not be inferred from this document.

## V8 feedback and V9 response

The V8 technical verifier passed, but the user rejected the creative result:

- `1 cm` and `100 m` looked too similar.
- ZapBara's reactions did not change enough.
- Damage differences blurred together at phone scale.
- The layout was understandable but not retention-worthy.

V9 changes the proof, not merely the labels. It uses moving real destruction footage, silhouette-level outcomes, four distinct full-body reaction sprites, and a final expectation inversion. Round 4 is deliberately broken into short setup/release, a separately labeled Pexels illustration, tracked real-drop action, impact, and a large powered-display result to avoid prolonged red-dirt monotony.

## TTS, captions, audio, and graphics

Canonical commentary is generated by `pipeline/capytech/generate_capytech_v9_tts.py` using the provenance-verified `natural_talker_male_qwen_blog` Base-ICL profile. The model loads once for all storyboard lines. Each output must be 48 kHz stereo PCM and must pass per-line `mlx_whisper` ASR with word timestamps before the fail-closed TTS manifest is written.

Timed narration, source quotes, source ambience, and SFX use real PCM leading-silence samples. The pipeline does not use timestamp-only `adelay`. Every hard-cut source-audio occurrence receives a 0.12-second fade-in and 0.20-second fade-out.

Captions use Komika Axis and the checked-in calibration artifact. Bursts contain 2-5 words, reconstruct text by concatenating raw `mlx_whisper` tokens, emphasize and animate one keyword, normally center at 55-65% frame height, and begin in the hook by 0.2 seconds.
