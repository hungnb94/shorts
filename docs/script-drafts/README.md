# Historical Script Drafts

Early finance Short script drafts retained for reference. These files are content, not executable code, and do not authorize production.

Naming groups:

- `01-*` through `06-*`: first script batch.
- `v2_*`: second iteration.
- `v3_*`: third iteration and clip-oriented concepts.

For an active production, use the matching `docs/production/*.md` contract and `output/projects/<project>/scripts/` assets instead of editing these historical drafts.
